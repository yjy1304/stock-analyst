# GE重点机型产地与采购价格核验：对联影医疗的竞争含义

研究截至：2026年9月28日。采购样本主要为2025年，生产与注册资料检索至研究日。

## 一、结论先行

**不能把GE在中国的全部市场份额，当成美国整机降税后受益的市场份额。** 本轮在高端CT、3.0T MRI、PET/CT三个方向都找到了境内注册或生产证据；同时，部分进口MRI和PET/CT仍值得逐单追踪。

对联影的判断分为两层：

- **长期竞争压力**：GE本土化意味着联影面对的是具备国内生产能力的国际品牌，而不是全部依赖进口的竞争对手。国产化本身可能影响交付、成本及采购参与能力，但具体项目资格仍以招标规则为准。
- **降税的边际冲击**：只有具体订单同时满足美国原产、税目覆盖、实际税负下降、价格让利传导、与联影产品可替代等条件，才可能形成明显增量压力。现有样本不足以量化联影将损失多少订单或收入。

本报告完成首轮公开资料核验，不是全国招采普查，也不是海关原产地认定。本轮不将此前讨论的“300亿美元安排”直接视为已经适用于这些设备的税率变化；政策文本、税目、执行日期及既有豁免须另行逐项核实。

## 四、对联影的具体影响

### 1. 高端CT：主要是本土化竞品压力，不宜全部归因于整机进口降税

事实：Apex Expert有境内注册证据，Apex Plus有北京产地采购样本。

判断：联影高端CT订单面临的GE竞争，在这些样本中已经不是简单的“国产对美国进口”。临床性能、配置、交付、服务和同口径报价仍是关键比较项。若GE境内生产使用美国进口部件，部件降税可能改善成本，但目前没有部件采购占比及实际税负，不能按整机价格测算受益。

验证重点：同一医院、相近临床需求下，联影与GE的投标配置、最终报价和评分；需要实际投标文件证明双方同场竞争，不能仅因产品属于同一类别就算作联影丢单。

### 2. 3.0T MRI：必须拆开无后缀Premier与MAX/XT/Elite

事实：无后缀Premier出现跨境报价；Premier MAX有天津生产及采购证据。

判断：进口Premier订单可列入关税敏感候选池，而天津型号首先属于本土化竞争。把整个Premier系列合并，会高估美国整机进口敞口。反过来，也不能因系列部分国产就断言所有Premier进口风险归零。

验证重点：瑞金样本原产地文件、合同税费承担条款、是否有既有减免；后续同型号同配置报价是否下降。跨境CIP部分的1,470万元不自动等于海关审定完税价格。

### 3. PET/CT：进口与境内生产并存，税目核验比品牌判断更重要

事实：医院存量清单列Discovery MI为美国来源，CEC公示同时列出北京生产的Max Pro、Future、Power。

判断：联影受到的竞争既可能来自进口设备价格变化，也可能来自GE境内生产型号扩张。当前证据无法比较哪一项影响更大。

验证重点：区分MI、Max、Max+、Max Pro等完整名称；核实新机合同和实际海关归类。**不能因为PET/CT名称包含CT，就认定一定适用某个CT税号或已纳入某项降税清单。** 存量设备维保需求也不能转成当年新增设备市场份额。

## 五、如何把“品牌份额”转为“联影受影响订单”

建议逐笔建立以下筛选表，而不是用GE全国品牌份额乘以假定降税幅度：

| 筛选环节 | 最低证据要求 | 缺失时如何处理 |
|---|---|---|
| ① 是否新增整机采购 | 中标公告＋合同标的与数量 | 维保、升级、配件单独列示 |
| ② 是否美国原产 | 批次原产地/报关材料，注册生产地址辅助 | 标为未知，不以品牌国籍代替 |
| ③ 是否实质降税 | 生效政策、具体税号、旧新有效税负、既有减免 | 不估算节税额 |
| ④ 是否传导到采购价 | 同配置报价、税费承担条款、前后合同 | 不假设100%让利 |
| ⑤ 是否与联影直接竞争 | 联影参标、技术资格、配置与评分 | 不把全部GE订单当成联影可争夺订单 |
| ⑥ 是否改变输赢或毛利 | 中标差额、报价变化、最终合同及公司披露 | 只能列风险，不能确认收入损失 |

可计算的指标应是“满足条件的订单金额占可比样本金额之比”，同时披露未知订单比例。现有便利样本不满足全国代表性，也未闭合上述条件，因此本报告不输出美国原产份额、关税受益份额或联影收入影响百分比。

分析上还需分开两种结果：联影可能通过降价保住份额但毛利承压；也可能保持价格、丢失部分订单。份额稳定不等于竞争无影响。

## 六、下一步验证优先级

1. **进口MRI税负链条**：优先补瑞金Premier合同、进口及税费附件。这是本轮价格口径最明确的跨境样本。
2. **PET/CT新机证据链**：先补Discovery Max/MI官方新机成交公告和注册证，再讨论美国原产与降税。Max Pro等北京生产型号单独建组。
3. **同场竞标证据**：每类挑选联影与GE实际同场投标的项目，核对配置、报价和评分。仅凭中标方公告不能知道联影是否参与及失败原因。
4. **政策落地后的可比重复样本**：按完整型号、配置、税费及服务范围分组，形成多期样本后再判断价格趋势；避免把历史配置差异解释成政策效果。

当前最稳健的投资研究结论是：**联影面对的GE竞争，并非主要可以用“美国品牌—美国进口—降税降价”这一条线解释；需要同时跟踪GE本土化和少数进口高端订单。** 这是竞争机制判断，不是买卖建议。
