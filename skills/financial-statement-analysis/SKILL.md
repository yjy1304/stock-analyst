# 上市公司财务分析

沿用兆易创新研究中的证据链：原始披露 → 统一口径底表 → 年度与单季度计算 → 三张报表交叉验证 → 业务原因判断 → 财务亮点与风险 → 下一期验证。复用方法，不复用某家公司的历史数值或结论。

## 选择分析范围

- 完整财报分析：最近三个完整会计年度，加最新中期或季度；最近八个可得单季度。数据不足采用最长可得连续区间并说明缺口。执行本文件全流程。
- 更新分析：先读已有报告与底表，核验新增及追溯调整数据，更新受影响的表、图与结论，保留未受影响内容。
- 本技能不包含依据关联交易额度推演产量、收入与利润的专项模型。关联方交易仍可作为财报附注中需要核验的财务风险证据，但不自动展开预测。

优先遵循当前项目AGENTS.md、用户指定市场、时间范围与格式。默认中文、合并报表、当地报告币种；研究对象有歧义时先确认。金融、保险等行业采用其适用指标，不硬套工业企业毛利率和存货框架。

## 首次分析时初始化目录

开始下载或生成公司资料前，先读取项目目录约定、检查根目录现有股票文件夹，并核对证券简称、代码和上市市场，避免因简称变更或别名为同一公司重复建目录。目录初始化是首次开展本地财报研究的准备步骤；仅回答概念问题或用户明确要求不落盘时不创建目录。

首次分析且没有对应公司目录时，在项目根目录下以证券简称建文件夹，并一次性创建三个固定分析目录以及财报所需的原始资料、原始数据和图表目录：

```text
证券简称/
  01_近3年财报趋势与分析/
    原始资料/
    原始数据/
    图表/
  02_主要挑战与机会/
  03_股价博弈点/
```

02和03在首次仅做财报研究时允许为空，保留后续研究入口，不为填充目录生成无关报告。临时提取、转换等中间文件有需要时再在01下创建tmp/。

已有公司目录时复用，只补齐缺失的上述目录；可使用mkdir -p等可重复执行的建目录方式，不覆盖、清空或迁移已有资料，不自动重命名旧目录。若目录名称对应的公司不明确、目标被同名文件占用或符号链接指向项目外，先核实冲突再写入。用户指定的目的地及项目AGENTS.md优先于默认结构；不要硬编码某台电脑的绝对路径。

创建后检查目录实际存在，并确认所有资料的输出路径都位于对应股票目录内。初始化不意味着自动启动02和03的分析，也不自动执行git初始化、提交或云端发布。

## 资料归档与来源核验

将所有公司专属原文、提取文本、数据、图表、脚本和中间文件放入对应证券简称文件夹。财报分析及其财务亮点与风险归01，行业竞争归02，估值与市场预期归03。不得把公司资料散落在项目根目录或项目级tmp中。sources/已有只读参考保持原位，不移动、覆盖或重命名。没有研究仓库约定时尊重用户的既有目的地，不自动创建云端副本。

1. 记录研究截至日期；“最新”以交易所或公司实际已披露文件核实，不依据搜索摘要或旧报告推定。
2. 优先交易所、公司IR及法定披露文件；二手平台用作定位与交叉核验。打开原文核对关键数字和单位；PDF表格存在错列、OCR异常时查看对应页图像。
3. 保存下载原文件及必要提取文本，不只留URL。来源清单记录标题、披露日期、报告期、URL、本地路径、页码/章节、下载日期。失败时注明未归档，不把摘要冒充原文。
4. 原始输入与测算输出分开；底表每个数据附期间、币种、单位、合并/母公司、累计/单季、来源位置、披露/测算标记。缺失值用空值或“不披露”，不填0。
5. 比较期有重述时采用同一最新可比口径并标注；不拼接不同业务分类、币种或合并范围。结论性引用链接指向对应披露页。

## 年度与单季度计算

年度底表至少覆盖营业收入、营业成本、归母净利润、扣非归母净利润、毛利率、归母净利率、经营现金流、研发投入、ROE、资产负债率、存货；增加应收账款、费用、预付款及应付款以支持盈利质量分析。研发投入区分费用化、资本化和当期摊销，不把费用化研发等同总投入。不可获得或不适用的指标解释原因。

季度底表至少包含单季收入、归母利润、扣非利润、营业成本、毛利率，以及收入与两类利润的同比环比；有数据则加现金流、费用及资产余额。计算规则：

- Q1直接取季报；Q2＝半年累计−Q1；Q3＝前三季度累计−半年；Q4＝全年−前三季度。优先采用公司直接披露、口径一致的单季数，并与累计差分核验。
- 差分适用于收入、成本、利润、现金流等流量。资产负债表余额不可按差分当作“单季余额”。
- 单季毛利率＝1−单季成本÷单季收入；归母净利率＝单季归母净利润÷单季收入。不能累计毛利率相减；ROE不靠相减还原，优先采用披露加权口径。
- 基期正值时增长率＝本期÷基期−1；基期为0记不适用；利润基期为负以扭亏、转亏、减亏及绝对额解释，避免误导百分比。利润率变动用百分点。
- 所有差分、比率、增速标为测算并保存公式。内部使用原精度，展示时再取整。
- 核验四季度之和等于全年，Q1+Q2等于半年；收入−成本等于毛利；资产＝负债+权益。差异不强行抹平，追踪重述、单位或OCR问题。

要计算八个季度的同比，需额外取得其对应上年基期，而不只下载八个季度。若资料无法取得，只留可核验增长率。

## 盈利质量与业务原因

按证据而非通用行业叙事解释拐点：

- 对照经营现金流、归母与扣非利润；现金流改善同时检查应付增加、预收/合同负债、存货和应收变化，不能以现金流大于利润证明全部利润已收现。
- 对比应收与存货的可比期增速和周转；不要把余额较年初增长与收入同比混为一谈。周转用期初期末平均余额除以对应期间收入/成本再乘期间天数，注明近似法及是否含票据、合同资产；半年不能套全年天数。
- 核对毛利率、销售/管理/研发费用率；拆解量、价、组合、成本、汇率与并表。没有销量和ASP时只给有出处的定性判断，不捏造量价贡献。
- 单列投资收益、公允价值变动、补助、减值及税率变化。税前收益不直接从税后归母扣除；区分计入损益与其他综合收益的投资升值，避免重复计入利润或估值。
- 研发资本化影响当期费用和未来摊销，需结合实际投入评价，不简单判作降本或造假。
- 按可比产品、地区、行业分析收入占比、增速、毛利率与毛利贡献。分部毛利不是净利润；未披露业务独立数据时不套用集团毛利率作为事实。

## 财务亮点与风险

完整报告必须单列“财务亮点”和“财务风险”两部分；更新报告需说明哪些判断被强化、削弱或新增。按对核心盈利、现金流和偿债能力的重要性排序，不为凑数量罗列无证据的优点或通用风险。

亮点优先识别：扣非盈利与收入同步改善、现金回收质量提升、毛利与费用效率改善、业务结构优化、资本回报和营运效率提升。区分结构性改善、周期性反弹、低基数和一次性收益，不能把一次性盈利当作持续经营优势。

风险优先核验：利润与现金流背离、应收与库存周转恶化、毛利率回落、非经常损益依赖、研发资本化和减值压力、商誉及资产可回收性、有息债务期限与流动性错配、受限资金及或有负债。按行业适用性选择；异常先作为待解释信号，不在证据不足时认定违规或财务造假。

每项结论给出以下要素，可用短段落或表格呈现：

| 要素 | 要求 |
|---|---|
| 数据证据 | 本期值、可比基期、变化及来源，明确年度或单季度 |
| 财务含义 | 解释如何影响盈利质量、现金流、资本效率或偿债能力 |
| 原因与持续性 | 区分已披露原因和分析判断，列明反证或替代解释 |
| 重要程度 | 按金额占比、趋势持续时间和业务影响说明，不使用无依据的评分 |
| 后续验证 | 指出下一报告期要核验的具体指标和支持或推翻结论的变化 |

同一现象可能同时构成亮点和风险，例如利润率上升伴随收入集中度提高，应解释两面性而不重复计数。没有足够证据支持亮点或重大风险时明确说明，不强行平衡。最终综合判断应回答：增长质量是否改善、改善能否持续、最需要警惕的财务变量是什么。

## 图表与交付

完整财报分析必须嵌入四类图：三年收入及归母利润、三年盈利能力、八季度收入及利润并体现同比或环比、经营现金流与净利润对照。有可靠分部数据时加结构图；非经常性损益显著时加归母与扣非对照。图表应支撑具体财务亮点或风险，更新分析仅更新受影响的图表。

图表保存到01下的图表/，优先PNG或SVG，在Markdown正文用相对路径嵌入；保留数据Markdown表及可复算数据/生成逻辑。标题、轴、图例、单位、时间与截至日期使用中文，图下注来源及测算方法。收入、利润、现金流、利润率跨图颜色一致；量级差异过大用分面，避免过多双轴、截断轴、3D和不可比较的饼图。年度与半年数不当成同长度周期画连续增长趋势。

实际渲染查看图表，检查中文字体、单位、标签、图例、截断和图表数据对应关系；不能只以文件存在或XML可解析判定可视化已验证。环境无法预览时明确限制。

正文先给结论，再给证据和解释，单列财务亮点与风险。每个重要结论明确区分趋势事实、原因判断、未来假设，并指出下一期哪些指标会支持或推翻判断。未来判断不等于公司指引，不自动扩展成买卖建议或估值报告。最后给可点击报告路径、资料缺口及验证状态，不宣称做过未执行的复核。

## 交付前检查

- 首次分析的目录已初始化，已有公司只补缺失目录；所有公司资料均在对应股票目录内。
- 期间、币种、单位、合并范围一致，披露日与报告期没有混淆。
- 原始资料已归档；来源、页码与关键数值能追溯。
- 年度及季度齐全，差分及增长率可复算，不适用指标有解释。
- 分产品合计与总表差异、取整及重述已说明。
- 原始披露、原因推断和未来假设各自标明，未把历史趋势直接当成未来承诺。
- 财务亮点与风险均有数据依据、持续性判断及验证指标，未用通用叙事替代公司证据。
- 图表已嵌入且实际查看，正文解释趋势而非仅堆图。
- 无覆盖无关文件、修改sources或无授权发布行为。
